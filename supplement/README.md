# Supplementary material for the building-deconstruction review

The reader-facing supplement is `Supplementary Material S1 - Extended Evidence and Methods.docx`. It describes the reported searches, exploratory model comparison, sensitivity analyses, quotation checks and additional subgroup results. Model comparisons are against one author's ratings, not an independently validated ground truth. The main manuscript retains those author's scores.

| File | Contents |
|---|---|
| `study_subgroup_scores.csv` | All 1,475 first-author publication–subgroup scores; a flag identifies the 1,375 building-scope assessments used in the manuscript. |
| `title_abstract_screening.csv` | Screening decisions and criteria for 353 records; abstracts are omitted. |
| `gap_register_summary.csv` | The 76 gap-statement summaries and their primary subgroup and study identifiers. |
| `Reconciliation_tables_figures_9_Nov_2026.xlsx` | Subgroup counts, pooled statistics, benchmark summaries and links to manuscript tables and figures. |
| `DATA_DICTIONARY.md` | Variables, score meanings, populations and calculation notes. |
| `MANIFEST.sha256` | SHA-256 hashes of the files listed above and the S1 document. |

The repository root contains the MIT-licensed software, dependencies, configuration and rubric. The original screening and evidence workbooks, abstracts, source PDFs, detailed quotations and private reviewer records are not included. Consequently the files here reproduce the tabulated score counts, but do not by themselves reproduce the literature search, independent source judgments or paid provider responses. Search-platform field settings and the SG01 reference date require further verification.

`SUPPLEMENT_LLM_EVIDENCE_CHECK.md`, `METRIC_AND_EVIDENCE_TRACE.md` and `CLAIM_CHANGE_LOG.md` are retained as historical project audit records; the reader-facing S1 and current datasets take precedence for the revised manuscript. These audit records may contain process commentary and should be reviewed before any public release.
